# Excitation-Coefficients-Kerr
List of Excitation Coefficients for a particle plunging in a Kerr Black Hole.

## DATA IN THE REPOSITORY:
  * **Circular equatorial**
    
    Excitation Factors $$B_{\ell mn}$$ and Coefficients $$C_{\ell mn}$$ for a non-spinning particle plunging in a Kerr Black Hole from the ISCO. The factors and coefficients are evaluated in perturbation theory, for gravitational perturbations ($$s=-2$$). The reported Excitation Factors have been computed in the Sasaki-Nakamura (SN) formalism.
    
    - **Data format:**
      
      $a/M, M \omega_R, \ M \omega_I, \ \mathrm{Re}(B_{\ell mn}^{SN}), \ \mathrm{Im}(B_{\ell mn}^{SN}), \ m_p^{-1}\ \mathrm{Re}(C_{\ell mn}), \ m_p^{-1}\ \mathrm{Im}(C_{\ell mn})$

    - **REFERENCE PAPER:**
    
      Quasinormal ringing of Kerr black holes. III. Excitation coefficients for equatorial inspirals from the innermost stable circular orbit, _M. Della Rocca, L. Pezzella, E. Berti, L. Gualtieri, A. Maselli_, [arXiv:2512.07959](https://arxiv.org/abs/2512.07959)
